# AdSpyLab vs ads-monitor — сравнение (предварительное)

- **Дата:** 2026-10-12
- **Статус:** предварительное. Сторона AdSpyLab взята из разбора от 2026-10-02 (видео автора + 30 скриншотов + лендинг, `adspylab-prior-analysis-2026-10-02.md`). Живой дашборд ещё не просмотрен — после прохода по нему (`adspylab-features.md`) таблицы ниже будут уточнены. Сторона ads-monitor — по коду, коммит `6c41d29` (`ads-monitor-features.md`).
- **Важно о классе продуктов:** AdSpyLab — платный SaaS ($490 за модуль, $999 за всё), покрывающий весь рынок web2app; ads-monitor — внутренний инструмент одной команды, который собирает только явно выбранных конкурентов. Часть разрывов — следствие этого, а не недоработка.

---

## 1. Итог в пяти пунктах

1. **Сбор и базовые метрики по объявлению у нас на уровне или лучше**: охват ЕС **и UK** с историей замеров и разбивкой страна × возраст × пол, место по показам, число копий, дни показа, сырые снапшоты Meta с переразбором, своё хранилище медиа.
2. **Главный разрыв — всё, что над данными**: аналитика во времени (Overview, Monthly Stats, профиль бренда), дельты 7d/14d и выживаемость, AI-обогащение креатива (транскрипт, OCR, топик/формат), поиск по смыслу, похожие креативы и концепт-семьи.
3. **Целиком отсутствующие модули**: Funnels Library (экраны воронок, пейволы, цены, стек) и Agent/MCP.
4. **Что у нас работает хуже при наличии фичи**: группировка копий (только точный sha256), поиск (подстрока без индекса), фильтры (нет страны/языка/платформы/домена/`≥`), сортировки (нет «прирост за 7/14 дней»), источник (только Meta), пропускная способность сбора (1 воркер, 300 проверок охвата в сутки).
5. **Из плана от 2026-10-02 сделано**: A1 (частично), A7 (полностью, сверх плана — UK и разбивка), rank (хотя был в «не берём»), Grid/Table. Не начаты: A2, A4, A5, B1–B4, C1–C4, D1.

## 3. Что у нас работает не так или хуже (при наличии фичи)

| Проблема | Почему важно | Где в коде |
|---|---|---|
| Группы копий только по точному sha256 | число копий занижено, одна идея = несколько плиток | `packages/db/src/creative-key.ts` |
| Объявление без скачанного файла — группа из одного; трекер без картинок не группирует картинки | группировка зависит от настроек скачивания | там же |
| Rank не сравним между трекерами и считается по накопленным показам всех стран | «Top by impressions» зависит от области списка | `feed-signals.ts`, `runner/rank.ts` |
| Охват только для объявлений, шедших в ЕС/UK (~48 % собранных) | US-only конкуренты остаются без метрики успеха — у AdSpyLab та же проблема | `ad_reach` |
| `max_ads` = 100 на прогон | крупные рекламодатели покрыты неполно, `complete=false` | `limits.ts:58`, `process-batch.ts:359` |
| Доменный трекер не видит редиректы и сокращатели | у Inflow 23 объявления по домену против 153 по странице | `matchDomain` в `process-batch.ts` |
| Поиск страниц по имени — максимум 15, новые одноимённые не отслеживаются | часть страниц конкурента выпадает | `jobs/resolve.ts` |
| 1 воркер, 1 Chromium, пауза 30–90 с между заданиями, 300 проверок охвата в сутки | не масштабируется под «весь рынок» | `single-instance.ts`, `boss.ts` |
| Флаг «новое» общий на всю команду | один просмотр снимает «новое» у всех | `markGroupsSeen` |
| Поиск `ILIKE` без индекса | замедлится с ростом базы | `feed.ts:528–533` |
| Ссылки CDN Meta живут ~5 дней | не скачанное вовремя потеряно навсегда | `ad_media.url_expires_at` |
| Алерты о сбоях только в UI | пауза источника или упавший воркер незаметны | `health.ts:40` |
| Рост диска ~10 ГБ на 2 000 объявлений без очистки, бэкап на том же хосте | операционный риск | OPS-02, OPS-04, OPS-09 |

Полный список технических рисков с `file:line` — в `ads-monitor-features.md`, §7.

## 4. Где мы сильнее

- Охват **UK** и **разбивка по стране, возрасту, полу** с историей замеров и адаптивным интервалом перепроверки.
- **Сырые снапшоты** Meta с версионированным нормализатором и переразбором — данные не теряются при смене парсера.
- **Лента новинок** с флагом «новое» и счётчиками по конкурентам — рабочий процесс «что появилось с прошлого раза».
- Место по показам **на каждый трекер** (у AdSpyLab — один глобальный rank).
- Полный контроль: свои данные, своё хранилище, нет подписки $490–999/мес.

## 6. Рекомендуемые следующие шаги (предварительно)

1. **Дешёвое на уже собранных данных:** ΔEU 7d/14d и ΔRank из имеющейся истории; `launched 7d/14d` и `active 7d/14d` по группам (A2); сортировка «Biggest EU gain»; фильтры страна / язык / платформа / URL contains; полнотекстовый индекс вместо `ILIKE`; миниатюры.
2. **Аналитика:** Monthly stats и профиль конкурента (A4 + A5) — ближайший аналог главного экрана AdSpyLab.
3. **MCP (D1):** read-only поверх запросов `@ads/db` — дешёвый способ закрыть «Agent + MCP» без своего чата.
4. **Обогащение (B1 + B2):** транскрипт, OCR, топик / формат — один раз на sha256; открывает фильтры и поиск по смыслу.
5. **Спайк по воронкам (C1):** проверить, сколько экранов квиза проходится автоматически.
6. **Эксплуатация:** алерты в Telegram/Slack о паузе источника и падении воркера — без них сбор может молча стоять.

Приоритеты будут уточнены после живого прохода по дашборду AdSpyLab.
